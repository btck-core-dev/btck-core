# BTC-K 创世前白皮书符合性审计与下一阶段目标

日期：2026-10-08（Asia/Shanghai）
结论：**当前 DEVNET 已证明核心链能够运行，但尚不能直接生成并公开有价值的 MAINNET 创世链。先关闭下列 P0 硬阻塞，再进行一次全新、空状态、可复现的主网创世。**

## 1. 审计边界与规范优先级

本审计逐项复核了：

- `docs/whitepaper.md`：项目愿景和高层约束。其首页已明确声明，早期 `1/41 + 10x` 发行方案仅作历史保留，不再是现行共识规范。
- `docs/tokenomics_v2_canonical.md`：现行代币经济规范 v2.4.0。
- `params/btck_parameters.json`：参数单一事实源的当前候选表达。
- `params/networks/*.json`：网络身份、创世块和功能开关。
- 共识、钱包、Stratum、P2P、AI 网关源码与测试。
- RC3/RC4 工作记录和当前工作树中的候选修复。

发生冲突时，不允许开发者临时选择“看起来合理”的版本。创世前必须把冲突写成一份签字冻结的主网共识规范，再由代码、参数、测试和发布制品共同实现。归档旧白皮书不具备规范效力。

状态定义：

- **已实现**：核心路径已接入且有自动测试或 DEVNET 证据。
- **部分实现**：存在代码/测试，但未接入主网关键路径、未完成生产验证或规范仍冲突。
- **未实现**：没有可用于生产的闭环。
- **冲突**：权威材料或代码之间存在不能带入创世的分歧。

## 3. 已确认符合的核心主线

以下内容不是纸面设计，当前已有实际实现：

1. 1 秒目标的 GHOSTDAG、kHeavyHash、蓝序发行和自适应 DAA。
2. 2100 万硬顶、4 年整数发行表、创世 0 奖励和资产守恒。
3. Phase 1 的 80% 矿工 + 15% Combo + 5% 生态基金拆分。
4. 12 小时冻结、未来 +100 块开奖、XOR 选胜者及流式锁仓框架。
5. 双密钥隐身地址、Schnorr 签名、共识成熟锁和钱包端不可误花过滤。
6. ASIC Stratum、PPLNS、官方池 5%/3%/1% 商业费率。

这些结论不代表已经允许主网发射；它们只说明无需推倒重做。

- **不得复制当前 DEVNET 数据库、余额、已挖奖励、checkpoint 或 genesis。**

初始难度校准证据：RC4 固定窗口结束时两台 KS0 合计实测约 `787.07 GH/s`（`ks01 ≈ 407.74 GH/s`，`ks02 ≈ 379.33 GH/s`），对应 1 秒数学候选 compact bits 为 `0x1c01659f`。2026-10-08 矿机恢复连接后，在 600 秒滚动窗口上连续取得 `751.33 / 773.32 / 765.08 / 752.25 / 739.42 / 743.09 GH/s`，两台矿机始终在线且重连后拒绝数为 0；中位数为 `751.79 GH/s`，对应 `daa.initial_bits = 0x1c017668`，已写入锁定但未批准的 MAINNET manifest。若算力回到 RC4 的 `787.07 GH/s`，数学期望约为 `0.955 秒/块`。

`pow_limit_bits` 是 DAA 允许下降到的最低难度安全边界，不等同于启动算力对应的 `initial_bits`；Genesis `bits` 又决定创世 nonce 搜索工作量。三者不得机械写成同一值。低算力退化模拟后，最低难度冻结为启动算力的 `1/16`，即 `pow_limit_bits = 0x1c176680`（约 `46.99 GH/s @ 1 bps`）；`daa.initial_bits` 与 Genesis `bits` 冻结为 `0x1c017668`。模拟表明 50% 和 10% 启动算力均能回到约 1 bps，6.25% 位于安全下限，1% 算力会在下限处约 6.25 秒/块而不会无限降难度。Genesis `nonce/expected_hash` 仍必须由真实 KS0 固定任务搜索产生。

### P0-5：正式候选包验收

- 在允许本地端口的正常 CI/隔离主机上重新执行全量测试，必须 0 failure、0 error。

## 5. 不应阻塞创世的发射后目标

为避免继续推迟主线，以下项目不作为 L1 创世硬条件：

- 第二台服务器和 7 天公网多节点 soak。它们显著降低单机故障风险，应在有收入或预算后尽快补齐，但白皮书没有要求必须先买第二台服务器才能生成创世块。
- Tor/I2P 默认集成。
- HTTP 402、L2 AI 五方分润、PoR、质押罚没、机器人钱包生产化。
- SatsChat、DEX、桥、交易所适配和流动性部署。

L1 主网与 GPU 生态在运行上明确解耦：MAINNET 创世、kHeavyHash 出块、L1 Combo 和 2100 万发行不依赖 GPU/Agent 服务。GPU 属于后续启用的 L2 商业网络；其 Combo 只接收真实 Agent 调用费中的流通 SatK，不得增发。冷启动阶段可由 5% 生态基金钱包按公开预算向通过 PoR/SLA 的 GPU 节点补贴，当前规范候选为前 180 天每日最多 500 BTC-K；该支出必须通过独立账本和公开交易执行，不得改写 L1 coinbase 或把“待机”伪装成已经完成的 Agent 收入。

这些功能在未完成前必须保持功能开关关闭，并在公开材料中准确标注为规划/实验性功能。
