# BTC-K ASIC 矿机接入指南

2026-10-18：SOLO 与 PPLNS 接入开放；PPLNS 首批真实付款经自动付款程序签名、广播并确认结算，后续自动付款已开启。
连接成功或账面收益不等于到账，应核对链上确认。正式钱包和校验文件见 [v3.2.13 Release](https://github.com/btck-core-dev/btck-core/releases/tag/v3.2.13)。

## 选择模式与端口

| 模式 | 当前直连接口 | 算力与初始难度指引 |
|---|---|---|
| PPLNS | `stratum+tcp://185.130.45.240:3332` | 共用 VarDiff；ASIC 初始难度128；自动付款已开启 |
| SOLO 入门 | `stratum+tcp://185.130.45.240:3333` | <1 TH/s；初始难度128 |
| SOLO 中档 | `stratum+tcp://185.130.45.240:3334` | 典型1–3 TH/s；初始难度4096 |
| SOLO 高档 | `stratum+tcp://185.130.45.240:3335` | 典型6–10 TH/s；初始难度16384 |
| SOLO 大算力 | `stratum+tcp://185.130.45.240:3336` | 典型20–100+ TH/s；初始难度65536 |

官方域名为 `pool.bitcoin-k.com`，对应端口相同。域名长连接历史问题仍待闭环；
目前直连IP稳定的矿机保持现有设置。域名与IP指向同一服务器，不构成独立备用池。

上述范围是初始难度建议，不是硬性算力限制。中间算力档先选相邻较低档，观察有效
份额频率与拒绝率，再由VarDiff调整。节点当前难度与ASIC固件下限可能覆盖初始档，
避免过滤有效区块。更高端口不会提高收益概率。1 TH/s = 1000 GH/s。

## 填写矿机设置

1. 在矿机管理页面打开 Mining Settings / Pool Configuration。
2. Pool URL 填所选完整接口，包含 `stratum+tcp://` 和端口。
3. Worker 填 `你的BTC-K钱包地址.独立矿机名`，每台矿机使用不同名称。
4. Password 通常填 `x`，绝不能填写钱包解锁密码。
5. 保存后检查连接、有效份额和拒绝率；矿池算力是份额窗口估算，不会瞬间等于矿机面板。

端口决定SOLO/PPLNS模式，改Worker或Password不会切换模式。备用槽位保持相同模式，
避免断线后意外从SOLO切到PPLNS或相反；没有独立备用地址时无需编造备用矿池。

## 收益与付款状态

SOLO普通区块奖励直接归属出块矿工，按公开规则收取费用块。PPLNS按最近10000个
有效份额的难度权重分配普通收益，可降低个人出块波动，不承诺固定收益。
不能要求所有算力都使用SOLO，PPLNS必须单独列出可用与付款状态。

当前配置费率为上线第1–7天5%、第8–30天3%、之后1%。PPLNS最低付款配置5 BTC-K，
UTC 00/06/12/18调度（北京时间08/14/20/次日02时），成熟输入过滤、付款6确认后结算。
待确认交易每30秒检查，与新付款批次分开；遇安全暂停或资金缓存未追平时不发起新付款。
低于最低付款额的余额继续保留，不保证固定到账时间或收益。

3337/3338是本机HTTP监控接口；16110是节点RPC，16111是P2P，均不是矿机接入端口。
完整英文说明见[官方矿池接入](mining_pool_access.md)。
