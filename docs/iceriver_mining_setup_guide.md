## 🚀 傻瓜式三步配置流程

```
 步骤 1: 查找矿机 IP ────► 步骤 2: 登录 WebUI 后台 ────► 步骤 3: 填入矿池并保存
    (按 IP Report 键)         (账号 admin / 12345678)        (30秒自动切算力)
```

---

### 第一步：查找矿机局域网 IP 地址

确保你的电脑与矿机连接在同一个路由器（局域网）下：

* **方法 A（官方按键法 - 最推荐）**：
  1. 下载并打开电脑端官方搜索工具 `IceRiver IP Reporter`（或通用的 `Advanced IP Scanner`）；
  2. 走到矿机前，轻按一下机身后面板网口旁的 **【IP Report】** 物理轻触按键；
  3. 电脑屏幕上立即弹出该矿机的局域网 IP（例如：`192.168.50.236`）。
* **方法 B（路由器后台法）**：
  1. 登录你的家用路由器后台（如 `192.168.1.1` 或 `192.168.50.1`）；
  2. 查看“DHCP 客户端列表”，找到设备名包含 `iceriver` 或 MAC 地址对应的 IP。

---

### 第二步：登录矿机 Web 管理后台

1. 打开电脑上的浏览器（推荐使用 Chrome、Edge 或 Safari）；
2. 在地址栏直接输入矿机的 IP 地址（例如输入 `http://192.168.50.236`）并回车；
3. 网页将弹出 IceRiver 官方深色管理界面登录框：
   * **Username (用户名)**: `admin`  *(若个别批次不正确，请尝试 `root`)*
   * **Password (默认密码)**: `12345678`
4. 点击 **【Login】**（登录）。

```

|                      ICERIVER MINER LOGIN                   |
|                                                             |
|   Username: [ admin      ]                                  |
|   Password: [ ••••••••   ]  <-- 默认出厂密码为 12345678      |
|                                                             |
|                     [   LOGIN   ]                           |
+-------------------------------------------------------------+
```

### 第三步：配置 BTC-K 矿池与钱包地址

1. 登录成功后，点击顶部导航栏的 **【Mining Settings】(挖矿设置)**；
2. 找到 **Pool Configuration (矿池配置)** 区域，依次准确填写以下内容：

```
+-----------------------------------------------------------------------------------------+
|                                    MINING SETTINGS                                      |
+-----------------------------------------------------------------------------------------+
| [Pool 1]                                                                                |
|   Pool Address: stratum+tcp://pool.btck.network:3333                                    |
|   Worker Name:  btck1s022fd5c7684238a4ee4505c01cef3353...0cff62.ks001                   |
|   Password:     x                                                                       |
+-----------------------------------------------------------------------------------------+
| [Pool 2 (Optional Backup)]                                                              |
|   Pool Address: stratum+tcp://backup-pool.btck.network:3333                             |
|   Worker Name:  btck1s022fd5c7684238a4ee4505c01cef3353...0cff62.ks001                   |
|   Password:     x                                                                       |
+-----------------------------------------------------------------------------------------+
```

#### 📌 填写要点与避坑准则：
* **Worker Name (矿工格式)**：必须严格遵循 `【你的BTCK隐身地址】.【矿机自定义名字】`。
  * **正确示范**：`btck1s022f...ff62.ks001`
  * ❌ **错误注意**：地址与名称之间只能用英文半角句号 `.`，切勿输入中文句号 `。` 或夹带空格！
* **Password (密码)**：输入 `x` 即可（矿池不设密码校验限制）。

---

### 第四步：强烈推荐 —— 开启风扇 100% 满速强冷

在同一个配置页面或 **【Hardware Configuration】** 下：
1. 找到 **Fan Speed (风扇转速控制)**；
2. 将默认的 `Auto (自动温控)` 改为 **`Manual (手动)`**，并将滑块拉至 **`100%`**；
3. **为什么必开 100% 满速？**
   * KS0 Ultra 双风扇满转可达 ~5,900 RPM，可将芯片算力板温度死死压制在 **55°C 以下**。
   * 低温能完全消除 ASIC 热降频，降低 Share 错解率（Reject Rate < 0.01%），大幅延长机器寿命并保障 100% 算力满额输出。

---

### 第五步：保存生效与仪表盘确认

1. 检查无误后，点击页面右下角的黄色/绿色 **【Save】(保存)** 按钮；
2. 矿机屏幕会提示 `Saved successfully. Applying configuration...`，机器内部程序将平滑热重启（耗时约 20~40 秒，不需要拔电源）；
3. 点击导航栏的 **【Home / Dashboard】(首页仪表盘)**，观察以下指标：
   * ✅ **Pool Status**：显示为 `Alive` 或 `Connected`（已连接）。
   * ✅ **Real-time Hashrate (实时算力)**：在 1~2 分钟内逐步爬升至额定算力（KS0 为 ~100G，KS0 Pro 为 ~200G，KS0 Ultra 为 ~400G）。
   * ✅ **Accepted Shares (接受份额)**：数值开始持续不断自增（如 1, 2, 5, 10...）。
   * ✅ **Hardware Error / Rejected**：维持在 0 或极低比例。

## ❓ 常见问题答疑 (FAQ)

### Q1: 矿机状态显示“Dead”或无法连上矿池？
* **排查 1**：检查矿池 URL 前缀是否完整带有 `stratum+tcp://`，端口号 `:3333` 是否输入正确。
* **排查 2**：检查路由器是否有防火墙限制出站 TCP 端口 3333，若局域网阻断，可尝试更换公共热点或检查 DNS。

### Q2: 矿机提交出现大量“Stale”或“Rejected”份额？
* **原因**：网络延迟过高（Ping 矿池服务器 > 150ms）或局域网 WiFi 丢包严重。
* **建议**：务必使用**有线千兆网线**直连矿机与路由器，切勿使用中继 WiFi。

### Q3: 忘记了矿机的管理员后台密码怎么办？
* 机器通电开机 2 分钟后，用卡针长按机身背面的 **【Reset】** 小孔 10 秒以上，待指示灯闪烁后松开，矿机将恢复出厂默认密码 `12345678`。
