# BTC-K Whitepaper

This filename is retained as the stable repository entry point. The former
582-day/10x/20%-Combo draft has been retired because it is not compatible with
the launched chain.

The sole normative tokenomics specification is:

- [BTC-K Canonical Tokenomics v2.4.1](tokenomics_v2_canonical.md)

The public presentation, which must not introduce different consensus claims,
is:

- [Public whitepaper](../web/whitepaper.html)

Consensus identity, genesis, DAA and checkpoints are defined only by an
approved `params/networks/*.json` manifest. L2 features remain disabled until
their separate activation gates are completed; their status does not change
the L1 public-launch criteria.
