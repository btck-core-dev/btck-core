矿工接入

向运营方获取专属 Worker 邀请资料，打开软件导入。选择本机已有模型、运行环境和 GPU，使用推荐或手动配置，然后连接。矿工无需域名、公网 IP 或端口映射，软件主动连接统一 HTTPS 网关。

平时 Pearl 挖矿、模型常驻；调用到来时暂停 Pearl，调用结束恢复挖矿。模型与 Pearl 配置使用矿工自己的路径、矿池和钱包。软件不捆绑模型或自动下载运行环境。

客户与 Agent

使用独立的 Agent 凭证访问 调用页面，或在工具包中设置网关 https://compute.bitcoin-k.com。查询当前在线模型后选择调用。Worker 邀请不能用作客户凭证。

实际用量按所选模型 KCU 费率计价；工具在客户自己的电脑执行。预算、签名回执和任务恢复示例见包内说明。

四张 RTX 4070 Ti SUPER 的 35B TP4、两张 RTX 3090 的 27B TP2（Windows + WSL2）已通过近 16K 上下文、工具调用及双节点并发验收；其他机器、任意模型、4bit KV、猜字与长期稳定性仍需各自验证。当前不提供主网充值、提现或链上结算。新模型需经目录准入与服务验证后才能接单。
