Verification

First compare the release-key fingerprint with the independently published fingerprint above. Do not establish trust using only the key bundled beside the download. Then run:

python3 scripts/verify_mainnet_release.py RELEASE_DIRECTORY \
  --trusted-public-key RELEASE_SIGNING_PUBLIC_KEY.pem

Expected result: "verification": "PASS".

Known limitations

  • The first 271,828 blocks were produced during a disclosed controlled Guardian phase; this is not presented as open mining from block zero.
  • L2 inference, DEX, bridges, wBTCK and exchange integrations are not enabled mainnet services in this release.
  • Tor/I2P transport is not built into the node or wallet by default.
  • Bitcoin K is experimental software. Verify binaries, back up wallet material offline and never disclose recovery words or private keys.
