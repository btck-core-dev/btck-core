Verify before running

Compare every artifact with SHA256SUMS and verify the detached release signature. Confirm the trust key independently: OpenSSH fingerprint SHA256:vCmJJMLpdfAGa5t4TllNx4oa146IReNLwqNAJ91DyDw. Do not establish trust solely from the key bundled beside a download.

python3 scripts/verify_mainnet_release.py RELEASE_DIRECTORY --trusted-public-key /path/to/trusted/btck-mainnet-release-ed25519.pub

Expected: "verification":"PASS". The release manifest binds the source commit, genesis hash, checkpoint#271828 and consensus fingerprint. The wallet was built twice in isolated roots with identical bytes.

Mining

Complete SOLO/PPLNS endpoints and hashrate guide. PPLNS uses3332; SOLO uses3333–3336. The PPLNS minimum is5 BTC-K, UTC batches00/06/12/18 and six-confirmation settlement. Safety holds can delay payments; unpaid credits are not confirmed receipts.

Limits

The macOS arm64 wallet is ad-hoc signed, not Apple Developer ID signed or notarized. No external security audit is claimed. L2 inference, DEX, bridges and exchange integrations are unavailable. The first271828 blocks were produced during the disclosed Guardian phase. Stable direct-IP miners should keep their current settings while domain long connections are verified.
